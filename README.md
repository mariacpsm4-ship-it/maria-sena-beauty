
# Maria Sena Beauty 💄

## Sobre o projeto

Maria Sena Beauty é uma aplicação web de comércio eletrônico desenvolvida como projeto acadêmico do curso Técnico em Informática.

A plataforma simula uma loja virtual de maquiagem e cosméticos, permitindo que os clientes naveguem pelo catálogo, adicionem produtos ao carrinho e realizem pedidos.

## Funcionalidades

### Cliente
- Cadastro de usuários.
- Login e autenticação.
- Visualização de produtos.
- Carrinho de compras.
- Finalização de pedidos.
- Escolha da forma de pagamento.

### Administrador
- Acesso restrito ao painel administrativo.
- Cadastro de produtos.
- Edição de produtos.
- Desativação de produtos.
- Gerenciamento de estoque.
- Visualização de pedidos.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- PDO
- XAMPP

## Banco de dados

O projeto utiliza MySQL para armazenar informações de usuários, produtos, marcas, categorias, estoque e pedidos.

O arquivo `schema.sql` contém a estrutura do banco de dados.

## Como executar o projeto

1. Instale o XAMPP.
2. Inicie o Apache e o MySQL.
3. Coloque a pasta `maria-sena-beauty` dentro de `htdocs`.
4. Crie o banco de dados `maria-sena-beauty` no phpMyAdmin.
5. Importe o arquivo `schema.sql`.
6. Configure as credenciais do banco no arquivo `config.php`.
7. Acesse pelo navegador:

http://localhost/maria-sena-beauty/

## Projeto acadêmico

Desenvolvido para fins educacionais, com o objetivo de praticar o desenvolvimento de aplicações web e a integração entre Front-end, Back-end e banco de dados.
